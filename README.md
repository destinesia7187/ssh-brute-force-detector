# SSH Brute Force Detector

Учебный проект на Python: обнаружение пяти неудачных SSH-входов с одного
IP за любые пять минут. Используются только стандартные библиотеки Python.
Проект создан с помощью ИИ для последующего самостоятельного разбора.

## Запуск

Откройте терминал в папке проекта. На Windows:

```powershell
py -3 detector.py
py -3 -m unittest -v
```

На Linux/macOS используйте `python3` вместо `py`.

Требуется Python 3. На текущем компьютере `py` запускает Python 2.7,
а `py -3` пока недоступен. Для этого занятия можно использовать встроенный
Python 3 из Codex. Из папки проекта:

```powershell
& "$env:USERPROFILE\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" detector.py
```

## Учебные данные

Все события синтетические, IP взяты из диапазонов для документации.

| IP | Сценарий | Ожидаемый результат |
|---|---|---|
| 192.0.2.10 | Две ошибки, затем успешный вход | Нет тревоги |
| 198.51.100.23 | Пять ошибок за 4 минуты 20 секунд | Тревога |
| 203.0.113.7 | Пять ошибок с интервалами 10 минут | Нет тревоги |

Ожидаемый вывод:

```text
[ALERT] 198.51.100.23: 5 failed logins | 10:00:10 - 10:04:30 UTC
```

## Как работает

1. Из строк `Failed password` извлекаются время и IP.
2. События сортируются по времени.
3. Для каждого IP хранится очередь попыток за последние пять минут.
4. Старые попытки удаляются из начала очереди.
5. При достижении порога создаётся первая тревога для этого IP.

Окно скользящее: оно считается относительно каждой новой попытки,
а не относительно фиксированных отрезков часов. Граница ровно в пять
минут включена. Успешные входы не обнуляют счётчик неудачных попыток.

## Ограничения

- Поддерживается только формат учебного файла: время UTC вида
  `2026-09-16T10:00:00Z`, IPv4 и сообщения `Failed password`.
  Другие строки пропускаются. Это не универсальный парсер Linux-логов.
- Файл целиком обрабатывается в памяти; наблюдения в реальном времени нет.
- За запуск выводится одна тревога на IP, включая повторные серии позже.
- Повторные строки считаются отдельными попытками.
- Тревога указывает на частые ошибки, но не доказывает атаку или взлом.
  Общий IP нескольких пользователей может дать ложное срабатывание;
  медленный или распределённый перебор может остаться незамеченным.
- Скрипт не подключается к серверам и не блокирует адреса.

## Первое самостоятельное изменение

Добавьте в `sample_auth.log` четыре неудачные попытки с новым IP
`192.0.2.55` в пределах пяти минут и запустите детектор. Затем добавьте
пятую попытку и запустите снова. Объясните, почему результат изменился.
